# Java Concurrency

A collection of Java examples and exercises for learning concurrency and multithreading.

## Topics

- **Threads:** Creating and running threads using `Thread` and `Runnable`.
- **Thread Lifecycle:** Starting, joining, and interrupting threads.
- **Synchronization:** Using `synchronized`, locks, and other mechanisms to coordinate access to shared resources.
- **Race Conditions:** Understanding and preventing issues caused by concurrent access to shared data.
- **Thread Pools:** Managing threads and executing tasks using `ExecutorService`.
- **Concurrent Utilities:** Exploring atomic variables, thread-safe collections, and other Java concurrency utilities.

## Requirements

- Java 21 or later
- Maven

## Running the Examples

Each example is a standalone Java class that demonstrates a specific concurrency concept. Run the desired class from your IDE or using Maven where applicable.

## Purpose

The goal of this repository is to build a practical understanding of Java concurrency, explore common problems, and learn techniques for writing safe and efficient multithreaded applications.
